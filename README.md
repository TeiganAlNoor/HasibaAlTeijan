# حاسبة ملتقى تيجان النور

تطبيق HTML/CSS/JavaScript ثابت، بلا إطار عمل أو بناء أو قاعدة بيانات. شغّله عبر HTTP؛ فتح `index.html` باستخدام `file://` لا يدعم تحميل الوحدات والبيانات المحلية بشكل موثوق.

## تشغيل محلي

يلزم Node.js حديث (تم الاختبار على 24):

```powershell
node scripts/serve.mjs
```

افتح <http://127.0.0.1:4173>. الخادم يستمع على الجهاز نفسه فقط؛ لا ينشر التطبيق. لإيقافه اضغط `Ctrl+C` في نافذته. يمكن تغيير المنفذ بمتغير `PORT`.

## التحقق

```powershell
node --test tests/exam-model.test.mjs tests/quran-navigation.test.mjs tests/quran-search.test.mjs tests/worker.test.mjs
node assets/fonts/verify-font.mjs
```

اختبارات المتصفح تستخدم `puppeteer-core` وChrome الموجودين خارج هذا المستودع؛ لا تُضاف تبعيات إلى التطبيق. شغّل الخادم أولاً، ثم حدّد مسار وحدة Puppeteer وChrome إذا لم يكونا في مواقع الاختبار الافتراضية:

```powershell
$env:PUPPETEER_MODULE = 'C:/path/to/puppeteer-core/lib/puppeteer/puppeteer-core.js'
$env:CHROME_PATH = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
$env:TEST_URL = 'http://127.0.0.1:4173'
node --test tests/browser.test.mjs
node --test tests/worker.test.mjs
node --test tests/preservation.test.mjs
node --test tests/interactions.test.mjs
```

الاختبارات مكتوبة باستخدام `node:test`؛ لا يوجد نظام بناء. محاكاة حجم الهاتف لا تغني عن تجربة جهاز لمس فعلي أو قارئ شاشة.

### نتائج التحقق الفعلي بعد اعتماد القراءة المتصلة

- اختبارات النموذج والتنقّل وسلامة النص والبحث والعامل: **68/68 ناجحة**.
- اختبارات المتصفح الوظيفية: **23/23 ناجحة**، تشمل اختبار المجموعة الرئيسي و22 حالة فرعية.
- اختبارات القراءة المتصلة والحركات واللمس: **10/10 ناجحة**.
- اختبارات الحفاظ على الأصل: **8/8 ناجحة**. المجموع **109 اختبارات ناجحة، دون إخفاق أو تخطٍّ**.
- بيئة التشغيل: Node.js 24.14.1 وChrome 157.0.8103.39، بعروض 320 و390 و768 و1024 و1440px. أُعيدت مقارنة خصائص الأصل في المتصفح، والتُقطت لقطات تحقق مباشرة خارج المستودع؛ توجد أيضًا 30 لقطة مقارنة محفوظة من الجولة السابقة.
- أظهر فحص Chromium الفعلي لعناوين السور خط `Noto Sans Arabic` محمّلًا محليًا، وليس مجرد اسم CSS أو خط بديل. العائلة المحسوبة تبدأ بـ`Teijan Quran`، وهو اسم تعريف الخط المحلي نفسه؛ تحققت مقارنة الأصل من بقاء بقية خصائص العنوان كما كانت. اختُبرت ثلاثة عناوين متزامنة في نطاق عابر للسور، إضافة إلى عنوان البقرة والنص القرآني.
- نجح فحص بصمة الخط وتغطية جميع محارف الآيات الـ6236، وفحص صياغة ملفات JavaScript/MJS التسعة عشر، و`git diff --check`. لم يُظهر كاشف التصميم نتائج غير مستثناة ضمن الإعدادات الموثقة الحالية؛ لا يعني ذلك اعتماد WCAG.
- شملت المقارنة النصية كل آيات المصحف الـ6236 وعناوين السور الـ114، لا مجرد عينة. في التشغيل المتوازي الأخير اكتمل بناء DOM خلال نحو 3701ms؛ استغرق الاختبار مع نقل النص الكامل ومقارنته 19654ms، وهو ليس زمن بناء القراءة وحده. استغرق تحديث علامة أثناء التجهيز 10ms، وكان مؤشر الانشغال فعّالًا حينها. هذه ملاحظات محلية وليست ضمان أداء لهاتف فعلي أو قياس FPS.
- التحقق المحمول محاكاة فعلية داخل Chrome، لا اختبار هاتف لمس مادي أو Safari/Firefox أو قارئ شاشة. صلاحية حافظة النظام تعتمد على المتصفح، والمسار البديل للنسخ اليدوي محفوظ ومختبَر. المسودات مؤقتة في ذاكرة الصفحة وليست حفظًا دائمًا.

## فصل المسؤوليات

- `js/exam-model.mjs`: سبع مسودات علامات مستقلة في الذاكرة. كل تعديل صالح يعيد الحساب والنسخ فورًا، وكل إدخال غير صالح يُبطل النتيجة والنسخ. الصفوف المخفية محفوظة ولا تدخل الحساب. المسح يمسح النوع الحالي وحده، دون تغيير عدد المواضع.
- `js/Teigan.js`: تحكم الواجهة، المسح المؤكّد، النسخ وبديله اليدوي، وموضع مصحف عالمي واحد. التنقّل بين الامتحانات لا يعيد تركيب المصحف أو تحميل بياناته.
- `css/TeiganCss.css`: النظام البصري والحركات الأصليان من المرجع `a7f1ad63f56393d3effbddec16ef3ac7a5f31de9`، بما فيه ترتيب تعريفات الحركة المكررة. `css/integration.css` يضيف تنسيق الميزات الجديدة فقط؛ تحسينات الجداول واللمس محصورة بعرض 576px وما دونه، دون تغيير قياسات التابلت والديسكتوب.
- `js/surah-combobox.mjs`: تصفح السور والبحث بالاسم؛ لا تُعتمد الكتابة حتى اختيار نتيجة باللمس أو لوحة المفاتيح.
- `js/popup-position.mjs`: إبقاء القوائم داخل مساحة الشاشة المرئية، مع قلبها للأعلى عند الحاجة ومراعاة تغيّر حجم لوحة المفاتيح.
- `js/quran-navigation.mjs`: الاختيار محفوظ بمرساة ثابتة؛ الموضع صفر يعرضه كاملًا مهما كان طوله. السابق/التالي يستعرضان مجموعات خارجه بطول أصغر القيمتين: 20 أو عدد آيات الاختيار. الرجوع إلى صفر أو زر «العودة إلى الموضع المختار» يعيد الاختيار كله. الاستعراض لا يعيد كتابة حقول الاختيار ولا يغيّر نمط الامتداد.
- `js/modal-controller.mjs`: إدارة الحوار الأصلي ودورة الفتح والخروج، مع قفل تمرير الخلفية واستعادة إعداداتها، والإبقاء على النافذة modal إلى نهاية الخروج. يُستخدم أيضًا لبديل النسخ اليدوي، دون إبطاء النسخ العادي.
- `js/quran-search.mjs`: سياسات منفصلة لتطبيع أسماء السور ونص القرآن، وفهرس كامل مع خرائط من الإملاء المبسّط إلى مواضع النص العثماني الأصلي.
- `js/quran-worker.mjs` و`js/quran-client.mjs`: بناء الفهرس والبحث خارج خيط الواجهة. المتصفحات غير الداعمة للعامل تستخدم المسار نفسه على الخيط الرئيسي مرة واحدة.
- `assets/quran/`: نسخة مصدر محلية مع بصمات وتوثيق المطابقة. النص الأصلي لا يُعدّل للعرض أو البحث. لا تعتمد النتائج على السور المفتوحة سابقًا أو على API حي. تُعرض جميع آيات الاختيار معًا دون ترقيم صفحات أو «تحميل المزيد»، بما فيها جميع السور الوسطية. نُقلت الإحالة المرئية إلى قسم «مصادر النص والتراخيص» في التعليمات، مع إبقاء ملفات الحقوق والبيانات.
- `assets/fonts/`: Noto Sans Arabic 2.012 مثبت بإصدار وبصمة وترخيص، ومحصور بالنص القرآني وعناوين السور المعروضة داخل المصحف. يُحمّل محليًا باسم عائلة CSS هو `Teijan Quran`. تبقى محددات السور وعناصر الواجهة على خطها السابق؛ استثناء العناوين يغيّر العائلة وحدها.

حُفظت أوزان الخصم والحدود الأصلية، بما فيها إمكان النتيجة السالبة ودرجة `101.0` عند اكتمال إضافتي دورة التثبيت. أُزيل زر الحساب اليدوي بالكامل. الخانة الفارغة تساوي صفرًا ضمن حساب بدأ بإدخال فعلي، لكنها لا تُظهر وحدها نتيجة. إدخال `0` صراحةً نشاط صالح يُظهر `100.0`، ومسح جميع المدخلات النشطة يعيد الحالة غير المحسوبة. تغيير عدد المواضع وحده لا ينشئ نتيجة.

لا تُقبل الكسور أو القيم السالبة أو القيم غير العددية كأعداد أخطاء. تظهر الرسالة «يجب إدخال عدد صحيح غير سالب (0 أو أكبر).» بجانب كل خانة مخالفة، وتختفي النتيجة والنسخ والمسح الرئيسي فورًا. لا يُعاد بناء جدول الإدخال أثناء الكتابة. تُحافظ حقول الأرقام على سلوك المتصفح الأصلي؛ قد يمنع المتصفح الحروف أو يحتفظ بإدخال وسيط غير مكتمل، ويُعامل الإدخال الوسيط غير الصالح كخطأ لا كصفر.

يظهر النسخ بجوار النتيجة داخل خليتها، وينسخ التقدير اللفظي للمراجعتين والعدد النهائي وحده لبقية الأنواع. يظهر المسح الرئيسي مع النتيجة الصالحة فقط؛ أما المسودة غير المكتملة أو غير الصالحة أو ذات البيانات المخفية وحدها فتتيح «إلغاء الإدخالات غير المكتملة». كلاهما يتطلب تأكيدًا ويمسح النوع الحالي فقط. يحذّر تنبيه واضح مع أيقونة وعنوان عند عدم بلوغ الحد: «غير مكتمل» للمراجعة تحت 95، و«راسب» للاختبارات والمسابقات تحت 90، و«يحتاج تحسين» للتثبيت تحت 90؛ يختفي التنبيه مع النجاح أو غياب النتيجة الصالحة.

هذه مسودات مؤقتة فقط: إعادة تحميل الصفحة تمسح العلامات والموضع. خط الواجهة Tajawal عبر Google Fonts اختياري؛ إذا تعذّر الاتصال يُستخدم خط النظام، بينما القرآن وبياناته وخطه محلية.

## القراءة المتصلة والتفاعل المعتمد

يعرض اختيار البقرة 1–45 الآيات الـ45 مباشرة، واختيار البقرة 260 إلى آل عمران 5 يعرض الآيات الـ32 مع عنواني السورتين. يعرض الملخص الدائم حدود الاختيار وعدد آياته، ويميّز مؤشر العرض بين الاختيار الكامل والمواضع المجاورة قبله وبعده. اختيار نتيجة بحث صراحةً ينشئ موضعها الجديد كما كان؛ أما مجرد استعراض السابق/التالي فلا يستبدل الاختيار.

لا يوجد حد أقصى اعتباطي للنطاق. للنطاقات الأكبر من 200 آية، تُجهّز العقد خارج DOM على دفعات تلقائية من 100 آية مع إتاحة خيط الواجهة بين الدفعات، ثم تُركّب القراءة كاملة في عملية واحدة. هذه دفعات تجهيز داخلية وليست صفحات أو حدود عرض. كل طلب أحدث يُلغي تجهيز الطلب الأقدم، ولا تعيد إعادة عرض الموضع نفسه أو التنقل بين الامتحانات بناء عقد الآيات دون حاجة. لا توجد افتراضية ذات فراغات أو تغيير تدريجي لارتفاع القراءة أثناء التمرير.

الأزرار الجديدة فقط تملك أيقونات SVG زخرفية بوزن متسق في بداية RTL، ورفع تحويم -2px وضغط -1px، بزمن 300ms والمنحنى الأصلي `cubic-bezier(.4,0,.2,1)`. التحويم محصور بالفأرة/المؤشر الدقيق، والحركة الجديدة تتوقف مع تقليل الحركة؛ الأصل لا يُعدّل.

حوار المسح يستخدم «تأكيد مسح العلامات» و«سيتم مسح علامات الاختبار الحالي فقط. هل أنت متأكد؟» وزري «إلغاء» و«نعم، امسح». للمسودات غير المكتملة عنوان ومتن موجزان مكافئان. يتلاشى الحوار والخلفية مع إزاحة 8px وتكبير من .97 خلال 300ms؛ يبقى التركيز محصورًا والتمرير مقفلاً حتى نهاية الخروج. حارس التأكيد يمنع المسح المكرر دون إخراج التركيز من النافذة.

خيار الامتداد يحافظ على checkbox حقيقي، قابل للفأرة وSpace واللمس، مع SVG زخرفي يرسم علامة الصح ويعكس الرسم خلال 300ms. تتغير الحقول فورًا، دون انتظار الرسم. لا يُخفى checkbox باستخدام `display:none`، وتظهر حلقة التركيز على العلامة المرئية. الرسم من شفرة المشروع، دون نسخ مكوّن الطرف الثالث أو إضافة مكتبة.

## الحفاظ البصري والحركي

يحتوي كل قسم على مرساة ثابتة في موضع المصحف الأصلي؛ ينتقل إليها نفس عنصر `shared-mushaf` دون إعادة بنائه. تبقى النتائج في موضعها الأصلي أسفل الأقسام، مع تفاصيل الأساس والبونص والنتيجة النهائية للتثبيت وشرح خصومات المسابقات.

اختبار `preservation.test.mjs` يقدّم النسخة المرجعية من Git عبر خادم مؤقت في الذاكرة فقط، ويقارن خصائص المكونات في Chromium عند 320 و390 و768 و1024 و1440px. بيانات API المرجعية هي عينات محلية مضبوطة، وليست اختبارًا لاعتمادية الشبكة القديمة. لحفظ لقطات فعلية خارج المستودع حدّد `PRESERVATION_SCREENSHOTS` إلى مجلد مؤقت قبل تشغيل الاختبار. مقارنة الخصائص لا تعني تطابق كل بكسل.

بناءً على طلب الاستعادة الصريح، لم تُستبدل ألوان الأصل أو حركاته القديمة؛ لا يملك النظام الأصلي وضعًا مخففًا للحركة. بقي انتقال البحث الجديد فوريًا عند طلب تقليل الحركة، وتُوقف انتقالات الأدوات الجديدة في هذا الوضع. أُضيفت فقط تغذية راجعة للتحويم والضغط والتركيز على الأدوات الجديدة بزمن `.3s cubic-bezier(.4,0,.2,1)`، دون تغيير حالتها الساكنة. كود الاحتفال الأصلي وألوانه وتوقيته وإطاراته محفوظة، وحدوده الأصلية موثقة، لكنه لا يُستدعى تلقائيًا أثناء الكتابة أو تجاوز حد أو التبديل أو النسخ؛ ولا يُشغّل نبض النتيجة مع كل إدخال.

استثناءات كاشف التصميم في `.impeccable/config.json` توثّق الهوية الأصلية المطلوبة، ولا تمثل ادعاء اجتياز WCAG. لا تُحذف اختبارات الوظائف؛ تشمل التحقق من أن الاحتفال الأصلي يعمل مرة واحدة عند بلوغ حدّ كل امتحان من الحدود السبعة (لا عند كل رقم يُكتب، ولا عند النسخ أو التنقّل)، والحساب الفوري وحالات الصفر والمسح والتحقق والتنبيهات والتنقّل والنسخ، والخط الفعلي لعناوين السور عبر بروتوكول Chromium.

## فهرس ملفات التغيير

الملفات الأصلية المعدّلة: `index.html`، `js/Teigan.js`، `css/TeiganCss.css`، `instructions.html`، `README.md`.

- `.gitattributes`: تثبيت نهايات الأسطر وملفات الخط الثنائية لحفظ بصمات البيانات عبر الأنظمة.
- `.impeccable/config.json`: استثناءات محدودة وموثّقة لعناصر الهوية والحركة الأصلية المطلوبة ولإطار الجدول الذي تتحقق من حواشيه اختبارات المتصفح؛ ليست شهادة توافق وصول.
- `css/integration.css`: تنسيق إضافات المصحف والقوائم والحوار والنسخ والمسح، وتحسينات الموبايل المحدودة.
- `js/`: `exam-model.mjs`، `surah-combobox.mjs`، `popup-position.mjs`، `quran-search.mjs`، `quran-client.mjs`، `quran-worker.mjs`، `quran-navigation.mjs`، `modal-controller.mjs`.
- `scripts/`: `serve.mjs`، `prepare-quran.mjs`.
- `tests/`: `exam-model.test.mjs`، `quran-search.test.mjs`، `worker.test.mjs`، `browser.test.mjs`، `preservation.test.mjs`، `quran-navigation.test.mjs`، `interactions.test.mjs`.
- `assets/quran/`: `quran.json`، `manifest.json`، `ATTRIBUTION.txt`، `README.md`.
- `assets/fonts/`: `NotoSansArabic-v2.012-e5ee313.ttf`، `OFL.txt`، `verify-font.mjs`، `README.md`.
